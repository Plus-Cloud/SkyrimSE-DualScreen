# SkyrimSE-DualScreen — English (master list)
# Format:  id = text
# {} is a value the app fills in (a number, a name, a version). Keep every {} in translations.
# Words in CAPITALS are shown in capitals in the app; translations can use their language's natural casing
# where capitals don't exist (Chinese, Japanese, Korean).
# Skyrim's own words (skills, months, Health/Magicka/Stamina, item types) should use the game's official
# translation for that language, so the companion matches the game.
