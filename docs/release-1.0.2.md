**Smoother Balanced mode, your own FPS, and a fixed updater.**

- **Balanced is now 40 FPS** (was 45). The Thor's screen runs at 60 or 120 Hz, so 45 FPS was never shown evenly and juddered slightly. 40 divides 120 exactly, so every frame stays on screen for the same time. If you were on Balanced, you're moved to 40 automatically.
- **FPS slider:** set any frame rate from 20 to 60, in the launcher (under Power) or in game (bottom screen ⚙). Values that suit your screen's refresh rate are marked **SMOOTH**, with one-tap picks (24 / 30 / 40 / 60 at 120 Hz).
- **Updating from inside the app no longer crashes.** In 1.0.0 and 1.0.1, tapping Update closed the app.

> **On 1.0.0 or 1.0.1?** Because of that bug, install this update by hand **once**: download `SkyrimSE-DualScreen-1.0.2.apk` below and open it on the Thor. It installs over your current version and keeps your saves, settings and mods. Updates after this one install from the banner in the launcher.
